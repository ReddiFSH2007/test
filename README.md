# Nearest-Neighbor Points (Exercise 1)

## Environment
- Language: C++
- Compiler: GCC 11+ or Clang 13+ (supports C++17)

## Build Instructions
Compile the code with `-O3` optimization:
```bash
g++ -O3 -std=c++17 src/main.cpp -o main
```

## Run Instructions
Run the executable:
```bash
.\main.exe
```
