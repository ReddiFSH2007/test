# Nearest-Neighbor Points (Exercise 1)

## Environment
- Language: C++
- Compiler: GCC 11+ or Clang 13+ (supports C++17)

## Build Instructions
Compile the code with `-O3` optimization:
```bash
g++ -O3 -std=c++17 src/main.cpp -o main
```

## Run Instructions
Run the executable:
### Linux / macOS:
```bash
# Via input redirection
./main < input.txt
# or input manually
./main
```
### Windows(CMD.exe):
```bash
# Via input redirection
main.exe < input.txt
# or input manually
main.exe
```

### Windows(Powershell):
```bash
# Via input redirection
Get-Content input.txt | .\main.exe
# or input manually
.\main.exe
```
